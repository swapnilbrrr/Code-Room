# Code-Room

Code-Room is a web-based technology learning platform developed for the CT050-3-2-WAPP Web Applications group assignment.

## Planned stack
- ASP.NET Core MVC (.NET 8)
- MySQL
- HTML5
- CSS3
- JavaScript
- Entity Framework Core

## Core modules
- Public learning pages
- Student registration/login
- Student dashboard
- Courses and lessons
- Multimedia learning resources
- Quizzes and results
- Progress tracking
- Admin dashboard
- CRUD management
- Form validation
- Role-based authorization

## Development
The project is intended to run in GitHub Codespaces and locally with the .NET SDK.
