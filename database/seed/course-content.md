## Content rules for implementation

- Every course has exactly 10 lessons in the initial release.
- Each lesson will later contain an explanation, example/practical activity, optional resource, and completion action.
- Each course will later have a short quiz based only on its lessons.
- The database seed should use these titles as the canonical lesson names.
- Content should remain educational and original; external resources can be linked where appropriate.
